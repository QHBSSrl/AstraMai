# 给测试用户的说明（0.1.3debug2）

> 这份是发给**帮忙测试的人**的。请连同两个文件一起发。
> 有任何问题，让他们把「设置 → 调试」里的内容截图发回来。

---

## 要装两个东西

| 装到哪 | 文件 | 说明 |
|---|---|---|
| **手机** | `ORhythm-0.1.3.apk` | 50 MB。直接装，允许「未知来源」 |
| **手表 / 手环** | `com.nowmes.orhythm.debug.0.1.3debug2.rpk` | 305 KB。用 **AstroBox** 装 |

**⚠️ 两个必须都装。** 只装一个不工作。

**⚠️ 装之前先把旧的卸载掉。** 旧版的包名是 `com.astranexus.astramai`，
新的是 `com.nowmes.orhythm` —— **不卸载的话桌面上会出现两个图标**。

---

## 装机顺序

### 1. 手机装 APK

- 用文件管理器点开 `ORhythm-0.1.3.apk`
- 提示"未知来源"→ 允许
- Play 保护机制可能提示一次 → 点「仍要安装」

### 2. 手机装 AstroBox（如果还没装）

- 已经在用 AstroBox 的跳过
- **必须装手机版**，电脑版不行

### 3. 手表装 RPK

1. 打开 **AstroBox**
2. 连上手表（首页顶部点设备）
3. 点「**安装快应用**」
4. 在文件选择器里找到 `com.nowmes.orhythm.debug.0.1.3debug2.rpk`
   （**记得切到「浏览」→「Download」**，默认的「最近」里可能没有）
5. 确认安装

安装中途可能会弹「要与 xxx 配对吗」——**点「配对」，并且手表上也要确认**。
（单方面点会配对失败，得重新配对）

### 4. 打开手机上的网桥

1. 打开 **ORhythm**
2. 底部「我的」→「手机网桥」
3. 把「启用网桥」打开
4. 应该显示「**已连接：你的设备名**」

**如果显示「等待手表连接」** → 手表和手机没连上，去 AstroBox 里连。
**如果显示「出错」** → 把错误文字截图发回来。

### 5. 手表上查一次分

1. 手表打开 **ORhythm**
2. 首页 → 查分
3. 能出成绩就说明通了

## 出问题怎么反馈

**手表上**：设置 → 滚到底 → **调试** → 点「设备信息」

把这一段截图给我：

```
类型 xxx｜型号 xxx
屏宽 xxx｜屏高 xxx
密度 xxx｜形状 xxx
APILv xxx｜平台 xxx
字号倍率 xxx%
```

**手机上**：手机网桥页面截图（状态那一行）。

---

## 已知限制

**手机上的 ORhythm 必须保持运行。**

切到后台或者被系统清掉之后，手环就查不了分了。
这个后面会做前台服务解决，现在只能先这样。

**手环 Pro 才需要网桥。** 手表（Watch 系列）自带联网，网桥只是备用通道。
