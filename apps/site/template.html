最常被问的

推分计算器

「我想打到 300 分，得打到多少达成率？」 从 B50 点任意一首就进，定数和当前成绩已经填好，**不用在表盘上打字**。 目标用 -5 / -1 / +1 / +5 调，还差多少实时算给你看。

同时显示这首谱的「天花板」—— 打满能到多少。

每次查完自动比

成绩对比

涨了 / 跌了 / 新进 / 掉出，四类分清楚。

掉出 B50 用灰色，不用红色 —— 那不代表你退步了，只是被别的谱挤出去了。

地下没信号

离线缓存

查过一次之后，断网也能翻上次的成绩，会标注是什么时候抓的。

一句话给答案

距下一档

距虹　还差 128 —— 到最高档就直说，不显示「还差 0 分」这种废话。

手表出配对码，电脑上填好友码，手表取回来。 数据在浏览器里先加密再上传，服务器只拿到密文。

常见问题

要钱吗？

不要。基础功能全部免费，没有内购也没有广告。

我的数据安全吗？

查分走的是落雪查分器和 osu! 官方 API， 我们只是把它们的结果整理成手表好看的形状。 你的账号密码我们从来拿不到（Phigros 是 TapTap 扫码换的令牌，只存在你手表上）。

为什么不支持 Arcaea？

Arcaea 官方没有公开 API，第三方方案要么要求改装设备、要么依赖别人的私有服务。 风险太大，暂时不做。如果以后官方开放接口，会第一时间跟上。

支持哪些设备？

小米手表 Watch S3 及以后（含 S4 / S5、REDMI Watch 5 / 6）， 以及小米手环 8 Pro 及以上。 更早的手环跑不了 Vela 应用。

一定要联网吗？

查分要联网。但查过一次之后会缓存，断网也能翻上次的成绩。
