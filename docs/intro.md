## ③ 详细版（适合 README / 群公告 / 应用介绍长文）

# AstraMai

**把你的音游成绩戴在手腕上。**

AstraNexus 团队做的腕上音游工具，跑在小米 Vela 上（手表 + 手环 8 Pro 及以上）。

## 支持什么

| 游戏 | 能查什么 |
|---|---|
| **舞萌 DX** | Best 50（旧曲 B35 + 新曲 B15）、逐条 Rating、DX 分数、谱师、物量 |
| **中二节奏** | Best 30 + New 20、单曲 Rating、定数 |
| **Phigros** | RKS、Best 30（TapTap 扫码登录一次） |
| **osu!** | Best Plays、pp、准确率、星数、MOD |

## 除了查分，还能做什么

- **推分计算器** —— 「我想打到 300 分，要多少达成率？」
  从 B50 点任意一首就进，定数和当前成绩自动填好，不用在表盘上打字。
- **成绩对比** —— 每次查分自动和上一次比，分「涨了 / 跌了 / 新进 / 掉出」四类。
  **掉出 B50 不等于成绩掉了**，所以用灰色标，不吓人。
- **离线缓存** —— 音游厅在地下没信号是常识。查过一次之后断网也能看。
- **距下一档** —— 「距虹 还差 128」，最常问的问题直接给答案。
- **登录二维码** —— 本地渲染，带有效期倒计时。
