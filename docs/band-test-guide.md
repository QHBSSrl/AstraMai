# 给群员的手环测试指引

> 可以直接复制到群里。

---

## 手环上为什么查不了分

小米手环没有网络模块 —— 它只有蓝牙。所以手环上的 AstraMai
需要**手机帮它上网**，中间要装一个「网桥插件」。

好消息：**你手机上的 AstroBox 本来就装了**（你就是用它装的 AstraMai），
所以只多一步。

---

## 怎么做（大约 3 分钟）

### 第一步：装网桥插件

1. 手机上打开 **AstroBox**
2. 进 **插件** 页
3. 找「安装插件 / 导入插件」，选 `astramai-bridge.abp`
   （装上 AstraMai 的那个群文件里就有，或者找群主拿）
4. 装完**启用它**

### 第二步：确认手环连着

手环要在手机的蓝牙范围内、并且连上了（AstroBox 里能看到设备）。

### 第三步：试一次

回到手环上，打开 AstraMai → 选舞萌 → 输入好友码 → 查询。

---

## 如果不行，帮我抓一下日志

这是**最关键**的一步，不然我猜不出问题在哪。

1. 手机 AstroBox → **插件** → 点开「AstraMai 网桥」
2. 找到**日志**（一般在插件详情里）
3. 把最近十几行**截图或者复制**发到群里

我主要看这几行：

```
[astramai] ✅ 网络可用（/api/health: 200）     ← 好
[astramai] ❌ 网络不可用：...                  ← 不好，把冒号后面的原文给我
[astramai] 已订阅 <设备名> (<地址>)             ← 好
[astramai] 现在没有已连接的设备                  ← 手环没连上
```

**四种情况我都能修**，但必须先知道是哪一种。

---

## 常见情况对照

| 你在手环上看到 | 说明 |
|---|---|
| 「这台设备不支持直接联网（手环没有网络模块）…」 | 插件没装，或者装了没启用 |
| 「网桥超时（25 秒没回）」 | 插件在，但没连上手机 / 手机后台被杀了 |
| 「网桥请求失败：…」 | 插件连上了，但它上网失败 —— 把冒号后面发我 |
| 转圈很久之后报错 | 同上，把报错原文发我 |

---

## 顺便说一下

**手表（Watch 系列）不需要这个** —— 手表自己能上网，装上就能用。

只有**手环**需要网桥。

---

## 我们想知道的

1. **你手环的型号**（8 Pro / 9 / 9 Pro / 10…）
2. **插件日志里那几行**
3. **能不能用**（能用 / 不能用 / 有时能用）

这三条发群里就行，谢谢！🙏
