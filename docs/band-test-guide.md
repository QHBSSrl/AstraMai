# 给参与测试的朋友 —— 手环网桥

> 这份可以直接转发。有不懂的地方群里问就行。

---

## 先说要测什么

小米手环**没有网络模块**，只有蓝牙。所以手环上的 AstraMai 需要**手机帮它上网**。

手机上的 AstroBox 装一个「网桥插件」之后，手环就能通过手机的蓝牙查分了。

**我们要验证的就是这条路通不通。**

---

## 你需要准备

1. **一台小米手环**（8 Pro / 9 / 9 Pro / 10 / 10 Pro 都行）
2. **手机上装好 AstroBox**（你装 AstraMai 时用的那个）
3. **手环上装好 AstraMai**
4. 手环和手机**蓝牙连上**（AstroBox 里能看到设备）

---

## 步骤（大约 3 分钟）

### ① 装网桥插件

1. 手机打开 **AstroBox**
2. 进 **插件** 页
3. 找「安装插件 / 导入插件」，选 `astramai-bridge-0.1.2.abp`
4. 装完**启用它**

> 找不到插件页的话：AstroBox 底部或者侧边栏一般有个「插件」入口。
> 装的时候如果报错，把报错原文发群里。

### ② 确认手环连着

在 AstroBox 里能看到你的手环，状态是「已连接」。

### ③ 打开插件日志看一眼

这是**最关键的一步**。

1. AstroBox → **插件** → 点开「AstraMai 网桥」
2. 找到**日志**（一般在插件详情里）

装好启用后，`on_load` 里会有一段自检，日志里应该出现下面某一行：

```
[astramai] ✅ 网络可用（/api/health: 200）      ← 好消息
[astramai] ❌ 网络不可用：...                   ← 把冒号后面的原文给我
[astramai] 现在没有已连接的设备                  ← 手环没连上
```

### ④ 在手环上试一次

回到手环 → 打开 AstraMai → 选舞萌 → 输好友码 → 查询。

---

## 三种结果，分别告诉我什么

### A. 能查到分 ✅

**最理想。** 说明整条链路通了。

告诉我：
- 手环型号
- 大概花了多久出结果
- 界面显示正常吗

### B. 报错，但报错里提到「网桥」或「超时」

说明链路**部分**通了。把**手环上显示的完整报错**发我。

### C. 报错说「这台设备不支持直接联网（手环没有网络模块）」

说明插件**没生效**。可能原因：
- 插件没装成功
- 装了但没启用
- 装的是旧版

请把**插件日志**发我。

## 有个心理准备

**这个功能在你们身上是第一次真机运行。**

前面所有测试都只能在电脑上模拟，手环上的蓝牙通道到底能不能撑住这么大的数据量
（一份 B50 的 JSON 有十几 KB，要拆成七八片发），**没人验证过**。

所以：

- 慢一点是正常的
- 第一次可能要等几秒
- 失败了我这边能改，但需要你那边的日志

**不管成不成，你这份数据都是最有价值的。** 谢谢 🙏
