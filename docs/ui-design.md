# UI 设计提案

> 2026-11-08。给 Flutter 三端（Android / iOS / 鸿蒙）用。
>
> 先定一条铁律：**不能做出第三个视觉风格**。手表端和官网已经有一套，
> 手机端必须是同一套的延伸，不是重画。

## 二、核心判断：首屏应该是「我」

**查分工具的通病是首屏放查询框。** 落雪、水鱼、各种 bot 都是这样 ——
因为它们是「查别人」的工具。

但**玩家 90% 的时间是在看自己**。所以：

### ❌ 不要这样

```
┌─────────────────────┐
│ [输入好友码   ] [查] │
│                     │
│  （空白，等输入）    │
└─────────────────────┘
```

### ✅ 应该这样

```
┌─────────────────────┐
│  ╭───╮              │
│  │头像│  QBHSSrl     │
│  ╰───╯              │
│                     │
│      15,023         │  ← 巨大数字，等宽字体
│       虹 · 銅        │  ← 段位色
│  距虹極  还差 977     │
├─────────────────────┤
│  旧曲 8396  新曲 3642 │
├─────────────────────┤
│ ┌──┐ 星空パーティー   │
│ │封│ Master 14.2    │
│ │面│ 100.5%  ⭐298   │
│ └──┘                │
│ ...（卡片流）         │
└─────────────────────┘
```

**第一次打开没数据时**才显示查询框，而且**默认填上次的**。

## 三、整体结构

**底部三个 Tab：**

```
  首页          搜索          我的
 (B50)        (曲库)      (设置/账号)
```

**为什么只有三个：**
- **推分、对比**是**从成绩点进去**的，不是独立入口 —— 它们服务于具体一首歌
- **二维码**是舞萌专属，放在首页的浮动按钮里
- 多了会让底部栏塞满图标，手机上每个只有 60px 宽，认不出来

## 四、成绩卡片（最重要的组件）

手机屏幕窄，**表格放不下**。用卡片，一行一首：

```
┌──────────────────────────────────────┐
│ ┌────┐  星空パーティーチューン         │
│ │ 封 │  ▎Master 14.2                  │
│ │ 面 │  100.5%          298           │
│ └────┘  ⭐⭐⭐⭐☆          🔴AP  🟡FS  │
└──────────────────────────────────────┘
```

**设计要点：**

| 元素 | 处理 |
|---|---|
| **封面** | 60×60 圆角 8，**必须有** —— 曲绘是音游的灵魂 |
| **曲名** | 一行，超长省略号 |
| **难度** | 左边一条 **3px 竖色条**（难度色）+ 难度名 + 定数 |
| **达成率** | 等宽数字，**颜色跟着评级变**（SSS+ 金 / SSS 金 / …） |
| **Rating** | 右侧**大号**，是这个卡片的主角 |
| **徽章** | FC/AP 用小圆点，不占地方 |

**为什么竖色条而不是整张卡片染色：**
整张卡染色之后，50 张卡片会变成一堵彩色墙，反而看不出哪首难。
竖条只在左边缘，扫一眼就知道难度分布。

## 五、评级颜色的用法

```
SSS+  #ffd700  金（带微光）
SSS   #ffd700
SS+   #ff9f43  橙
SS    #ff9f43
S+    #4fd6ff  青
S     #4fd6ff
AAA   #a855f7  紫
AA    #a855f7
A     #3ddc84  绿
其余   #9bacd0  灰
```

**同一个颜色用两档** —— 因为再细分就认不出来了。
玩家只关心「金 / 橙 / 青 / 紫 / 绿 / 灰」这六档。

## 六、推分计算器

从成绩卡片点进去，**定数和当前成绩已经填好**：

```
┌──────────────────────────────────────┐
│ 星空パーティーチューン                 │
│ Master 14.2   当前 100.5% = 298       │
├──────────────────────────────────────┤
│  目标                                 │
│      ╭─────────────────────────╮      │
│      │      300                │      │  ← 大数字
│      ╰─────────────────────────╯      │
│   [-5]  [-1]   [+1]   [+5]           │
├──────────────────────────────────────┤
│  需要打到     100.87%                 │  ← 实时算
│  还差          0.37%                  │
├──────────────────────────────────────┤
│  这首打满最多  307                    │  ← 天花板
│  目标可达 ✅                          │
└──────────────────────────────────────┘
```

**如果目标打不到：**

```
│  这首打满最多  307                    │
│  ⚠️ 目标 320 打不到，换一首吧          │
```

**不说「还差 13 分」** —— 那是废话，用户不知道 13 分意味着什么。
直接说「打不到，换一首」。

## 七、成绩对比

查完分之后，顶部出现一条**可折叠的横幅**：

```
┌──────────────────────────────────────┐
│  ↑ 112   3 涨 · 1 跌 · 2 新进    [展开]│
└──────────────────────────────────────┘
```

展开后：

```
涨了
  +12  曲名 A   Master 14.2   298 → 310
跌了
  -5   曲名 B   Expert 13.5   285 → 280
新进
  +98  曲名 C   Master 14.0           298
掉出
  ——   曲名 D   Master 13.8   290 → 不再 B50
```

**「掉出」用灰色不用红色** —— 那不代表退步，是被别人挤出去了。

## 八、手机独有的三块

### ① 成绩历史曲线

「我的」页里：

```
┌──────────────────────────────────────┐
│  Rating 变化                          │
│  15,200 ┤                        ╭─   │
│         │              ╭────╮───╯     │
│  14,800 ┤        ╭─────╯              │
│         │  ╭─────╯                    │
│  14,400 ┼──╯                          │
│         └────────────────────         │
│          10/12  10/19  10/26  11/02   │
└──────────────────────────────────────┘
```

**每次查分存一个快照**（rating + 时间戳），画折线。
手表存不下这个（只有 6 份缓存），手机可以存几百份。

### ② 分享成绩图

长按成绩卡片 → 「分享这张图」，生成一张竖版长图：

```
┌──────────────────┐
│   AstraMai       │
│                  │
│   QBHSSrl        │
│   15,023  虹     │
│                  │
│  ┌────┐ 星空パー  │
│  │封面│ Mas 14.2 │
│  └────┘ 100.5%   │
│         298      │
│                  │
│  qq 群 308532898  │
└──────────────────┘
```

**为什么值得做**：玩家会发到群里炫耀，这是**免费的推广**。

### ③ 多账号

「我的」页可以存多个：
- 自己（舞萌 + 中二 + Phigros）
- 朋友（只存舞萌）

**切账号不重新输入** —— 手机上打字成本比手表低，但也没低到愿意天天打。

## 九、动效（克制）

只做两处：

1. **Rating 数字滚动** —— 从 0 滚到实际值，400ms。这是唯一的"仪式感"。
2. **卡片入场** —— 列表滚动时淡入，不做位移。

**别的都不做。** 查分工具不需要花哨动效，用户等的是数据。

---

## 十、深浅色

**先只做深色。**

理由：
- 手表端是深色，官网是深色，手机端换浅色会像另一个产品
- 音游玩家群体对深色的接受度极高
- 浅色要重做一整套灰色层级，工作量翻倍

**以后要加浅色，把颜色抽成 `ThemeExtension` 就行** —— 现在按这个结构写。

## 十一、和现有产品的差异（一句话）

| | 落雪 / 水鱼 | AstraMai 手机端 |
|---|---|---|
| 首屏 | 查询框 | **你自己的名片** |
| 成绩 | 表格 | **卡片 + 封面** |
| 推分 | 自己算 | **滑动条实时算** |
| 对比 | 数字差 | **分类 + 可展开** |
| 历史 | 没有 | **折线图** |
